# 我的课表 v1.5.5

这一版修掉课表的手感问题：拖动不再被锁定在横或竖一个方向。

## 自由平移

- 手指画到哪里内容就跟到哪里：一次滑动可以同时换到别的星期和别的节次，斜向拖动不再需要分成两次操作。
- 松手后按手势速度继续惯性滑行，新一次触摸立刻停住。
- 双指捏合缩放的同时也能直接拖动定位。
- 惯性按时间积分实现，与刷新率无关；低端机上不会出现“滑不动”或“滑一半”的情况。

## 兼容性

单轴滑动、`performScrollTo` 定位、缩放宽档与“捏回全览”吸附行为全部保持原样；无障碍与语义滚动仍走系统滚动容器，未受影响。

## 安装与验证

要求 Android 7.0+。沿用原正式签名，可覆盖升级。附件只有 ARM64 与 ARMv7 两种 APK、对应源码与 `SHA256SUMS.txt`，不含 x86/x86_64 与 OCR 模型权重，开源协议 GPL-3.0-only。

Android 15（411dp）与 Android 7.0（360dp）各跑通同一套 57 项设备测试，其中包含“一次拖动同时移动两轴”和“快速滑动比慢速拖动滑得更远”。详细范围与边界见 [验证记录](../product/1.5.5/VERIFICATION.md)。
