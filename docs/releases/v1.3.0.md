# 我的课表 v1.3.0

首个 GitHub Release，沿用应用内部的 1.3 系列版本号。提供 Kotlin/Compose 原生 Android 应用，同时保留 Web/PWA。

## 本版功能

- 课程、考试与日程管理；教学楼和教室分栏、可选单双周及明确周次、整天调休。
- 一屏整周/展开课表，手动填写/图片识别/数据备份入口；自定义每天 1–48 节及起止时间，连堂课连续显示。
- 默认提前 10 分钟课程提醒，支持恢复与去重；桌面小组件显示最近三次课程。
- 用户从 hf-mirror.com 主动下载 PP-OCRv6 tiny（6.3 MB）/small（31.2 MB）后离线识图；OpenAI 兼容 API 导入。识别结果逐项确认后保存。
- 局域网 MCP：固定可轮换 Token、课程/考试/调休查询和编辑、可选逐次写入确认。
- 原生与 Web 的完整 JSON 交换，保留数据集元数据和扩展字段。
- GPL-3.0-only，保留第三方版权、许可证和源码来源；设置中可离线查看许可全文。

## 安装与升级

首次安装下载 APK 即可。已有 debug 版的用户请先导出 JSON 备份，再卸载旧版、安装首发版并导入备份；两者签名不同，无法覆盖安装。后续维护者发布版本使用同一 release 密钥。

源码构建：JDK 21、Android SDK 36、Node.js 22+；先在 `apk/` 执行 `npm ci`、`npm run sync`，再进入 `android/` 执行 Gradle。完整步骤见 [构建说明](../../apk/构建APK.md)。自行修改后可使用自己的 Android 签名密钥安装。
