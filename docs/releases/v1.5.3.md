# 我的课表 v1.5.3

这一版处理课表的留白与底栏占用，让同样的屏幕能显示更多课程。

## 课表密度

- 节次高度改为按内容分配：只有课程覆盖到的节次会被撑高，空节次保持紧凑。
- 课程卡片只显示实际存在的信息，没有地点或教师时不留下空行；单节课程不再重复显示节次。
- 同一时段的并行课程与连堂课程仍严格对齐，跨天共用同一套行边界。

## 顶部与底栏

- 顶部压缩为三行：标题与操作、周导航、以及仅在存在下一节课时出现的单行摘要。
- 底栏改为居中的圆角窄条，宽度约为屏幕的 92%、上限 420dp，四个标签各占等宽槽位，图标与文字不再被裁切。

## 缩放与小组件

- “标准”档每列固定 196dp；“紧凑”档缩到 70% 列宽，课名折行显示，适合一次看到更多课程。
- 桌面小组件内容与圆角边框之间增加左右和上下内边距。

## 安装与验证

要求 Android 7.0+。沿用原正式签名，可覆盖升级。附件只有 ARM64 与 ARMv7 两种 APK、对应源码和 `SHA256SUMS.txt`，不含 x86/x86_64 与 OCR 模型权重，开源协议 GPL-3.0-only。

单元测试、Android 15 设备测试（固定课表、双向滚动、连堂、末节定位、底栏与小组件 60 个渲染组合）全部通过。详细范围与边界见 [验证记录](../product/1.5.3/VERIFICATION.md)。
