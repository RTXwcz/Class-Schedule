## 边界与后续验证

此次设备测试使用本地 x86_64 调试构建；发布 APK 仅为 arm64-v8a 和 armeabi-v7a，单独检查签名、ABI 与 ELF 架构。没有在 ARM 实体设备上全面重跑，也没有覆盖所有厂商后台策略或完整 TalkBack 操作。OCR 测试使用生成的中文样本，不能代表真实课表准确率基准。没有使用真实 API Key 进行付费 OpenAI 调用。

MCP 当前采用局域网 HTTP，未提供 TLS；Keystore 只保护本机保存的秘密。普通课表可能参与 Android 系统备份，导出 JSON 为明文。这些边界已写入产品文档。

## v1.4.2 追加审查

本次以 v1.4.1 为基线，独立只读审查本轮变更后逐条复现和修正。

| 发现 | 最终处理 |
| --- | --- |
| 缺星期表头时可能把课程归到相邻列 | 没有明确格框且星期序列有缺口时保留未知；新增缺列回归 |
| 同格独立短课程被合成标题 | 收紧短尾和满行证据，保留“高等数学”和“英语”等独立课程 |
| 一个放大候选复用到多个原文字框 | 拒绝同时覆盖多个原框的候选，保留原定位 |
| 修复书名号可能破坏合法内层圆括号 | 追踪括号层次，覆盖嵌套标题回归 |
| 返回保留草稿后，新识别可清除旧修改 | 界面与 ViewModel 均阻止已有草稿时发起新识别，必须先保存或确认放弃 |

Widget 的后台启动授权只用于显式 MainActivity PendingIntent，目标解析仅接受两个导航入口；没有发现能驱动任意文件、数据库写入或外部组件启动的新增链路。JNI 边界精确保留，不为 MCP 添加整包保留规则。最终 R8 ARM64 包实际完成双模型 OCR 和 MCP 鉴权、确认写入及读回。

最新兼容矩阵、90 项单测、30 场景渲染与真实图片验证范围见 [v1.4.2 验证记录](../product/1.4.2/VERIFICATION.md)。旧版验证记录保持其当时范围。
