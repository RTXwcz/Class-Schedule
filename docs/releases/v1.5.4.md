# 我的课表 v1.5.4

这一版把课表的浏览方式分成两种：默认**全览**一屏看完整周，需要细节时切到**拖动**档左右滑动，两档之间还可以双指捏合连续缩放。

## 两种浏览方式

- **全览（默认）**：列宽按屏幕宽度自动计算，七天同屏，课名折行显示，先看全局再抠细节。
- **标准** 92dp / **宽松** 130dp：固定列宽，一屏约 4 天 / 3 天；左右拖动看不同天，上下拖动看不同时段。
- 在课表上双指捏合即可在两者之间连续缩放（40–220dp），捏到比全览还窄时自动吸附回全览，不会留下半个屏幕的缝。
- 右上角按钮显示当前档位，点按按“全览 → 标准 → 宽松 → 全览”循环，切换时保留横向浏览位置。

## 显示细节

- 全览档的课程卡片不再重复“第 X–Y 节”：卡片高度已经表示跨了几个节次，单双周标记仍然保留。
- 节次高度仍按内容分配，并把卡片内缩与行间距计入需求，窄列长课名在 Android 7 的折行规则下也不会被裁。
- 表头为“周几 + 日期”两行，窄列中居中；时间刻度与星期表头分轴滚动、始终对齐。

## 安装与验证

要求 Android 7.0+。沿用原正式签名，可覆盖升级。附件只有 ARM64 与 ARMv7 两种 APK、对应源码与 `SHA256SUMS.txt`，不含 x86/x86_64 与 OCR 模型权重，开源协议 GPL-3.0-only。

Android 15（411dp）与 Android 7.0（360dp）各跑通同一套 55 项设备测试，覆盖全览、拖动、双指缩放、双向滚动与小组件渲染。详细范围与边界见 [验证记录](../product/1.5.4/VERIFICATION.md)。
