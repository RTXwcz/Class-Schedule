# 我的课表 v1.7.0

这一版把上一轮对抗式审查发现的问题逐条修掉：导入反馈、MCP 加固、迁移测试、冲突卡片编辑、云端作息、发布守卫与备份容错。

## 用户可感知的变化

- 图片导入后，复核页会显示“已追加 N 门课程，M 门待补充”，不再只看到报错。
- 全览档里同一格有多门冲突课程时，点卡片会先让你选择要编辑哪一门。
- 云端识别（OpenAI 兼容接口）也会带回一天作息，和本地 OCR 一样可以“应用为每日作息”。
- 教师姓“楼”不再被当成教学楼；节次跳号的作息表也能识别；备份里的周次写成 “1-8,10” 也能导入。
- 设置 → AI 连接新增公共网络安全提示。

## 开发与发布

- MCP 服务增加滑动窗口限流（每对端 10 秒 60 次）与 1 MiB 请求体积上限。
- release 构建缺少签名环境时直接失败，避免误产未签名包；CI 增加 release 变体编译与 lint。
- 新增 Room 迁移测试（3→4）与导入持久化、冲突选择、限流等回归测试。

## 安装与验证

要求 Android 7.0+。沿用原正式签名，可覆盖升级。附件只有 ARM64 与 ARMv7 两种 APK、对应源码与 `SHA256SUMS.txt`，不含 x86/x86_64 与 OCR 模型权重，开源协议 GPL-3.0-only。

单元测试 109 项、Android 15 设备测试 70 项全部通过。详细范围与边界见 [验证记录](https://github.com/RTXwcz/Class-Schedule/blob/v1.7.0/docs/product/1.7.0/VERIFICATION.md)。
