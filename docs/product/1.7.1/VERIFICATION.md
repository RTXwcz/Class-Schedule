# v1.7.1 识别拆分与卡片信息收敛验证

按导出的课表数据（15 门课）复现出的两个问题逐条定位并修复，日期为 2026-09-13。

## 问题与处理

| # | 现象 | 根因 | 处理 |
| --- | --- | --- | --- |
| 1 | `微积分（甲）I` 被识别成 `微积分（甲）` 与 `I` 两条记录 | 标题折行后，末行的短编号自成一块，且带着地点、教师等明细，被解析器当成独立课程 | 新增标题后缀判定：长度 ≤ 3、只由拉丁字母/数字/罗马数字/甲乙丙丁/括号组成、紧邻上一门课且上一门课没有明细时并入课名 |
| 2 | 课表卡片上出现 `1-8周`、`秋冬{第1-8周|3节/周} / 童雯雯 / 紫金港东2-204` 这类重复信息 | 卡片详情同时输出了节次区间、周次列表和课程备注，备注又由同一批字段拼成 | `courseDetails` 只保留科目、地点（教学楼/教室/地点备注）、教师与非每周的单双周标记；节次与周次不再上卡片 |
| 3 | 导入后的备注里堆着教师、教学楼、教室、周次 | `meaningfulNote` 只按行去重，不判断这一行是否已经落到独立字段 | 备注改为按已解析字段过滤：周次行、仅星期/节次的行、命中教师或教学楼的行走掉，只留“需自备实验服”这类额外信息 |
| 4 | 设置 → 图片导入罗列 `deepseek-flash`、`qwen-vl-max` 等推荐模型 | 界面里带了一段模型建议 | 删除建议文案，只保留“地址填服务根地址即可，保存时自动补 /chat/completions” |

## 验证证据

| 检查 | 结果 |
| --- | --- |
| 单元测试 | 110 项全部通过（新增 `splitsNothingWhenATitleEndsWithALatinSuffix`、`dropsDetailLinesFromTheNoteButKeepsExtraRemarks`） |
| Android 15 设备测试 | 80 项中 76 项通过（新增 `cardsShowOnlyCoursePlaceTeacherAndHideWeekListsAndNotes` 与 `FixedTimetableTest` 全套 13 项）；4 项 OCR 诊断用例按环境前提跳过（需已下载模型或显式指定图片） |
| 导出数据复现 | 用用户导出的 `class-schedule.json` 中原样的 `微积分 (甲)` + `I` 两条记录构造用例，解析后合并为一门、教师/教学楼/教室正确、备注为空 |
| 卡片渲染 | 设备测试断言全览档卡片内出现课名、`理科楼 A301`、`教师 张老师`，且 `1-8周` 与备注文本在课表上不存在 |
