# 我的课表 v1.6.1

修复 1.6.0 的最窄档列宽问题：并行课程多时列会被压到 20 多 dp，日期被折行、“教学楼 + 教室”被挤没。这一版把最窄档恢复成一天一列、七天平分屏宽。

## 修复内容

- 最窄档每天固定一列，列宽按七天平分（411dp 屏约 49dp、360dp 屏约 42dp），星期与日期、教学楼与教室完整可读。
- 同一天时间冲突的课程不再并排挤宽整周，而是在该天列内合成一张卡片，逐条列出课名与地点，中间用细分隔线分开。
- 星期表头拆成“周几”“日期”两个单行标签并禁止换行，日期不会再出现“09/0 / 7”。
- 标准 / 宽松档保持并排分栏，方便对照冲突课程。
- 修复切档时布局被缓存、合并结果不刷新的问题。

![并行课程多时仍然一天一列](https://github.com/RTXwcz/Class-Schedule/blob/v1.6.1/docs/product/1.6.1/overview-clash-column.png)

## 安装与验证

要求 Android 7.0+。沿用原正式签名，可覆盖升级。附件只有 ARM64 与 ARMv7 两种 APK、对应源码与 `SHA256SUMS.txt`，不含 x86/x86_64 与 OCR 模型权重，开源协议 GPL-3.0-only。

Android 15（411dp）与 Android 7.0（360dp）各跑通同一套 61 项设备测试，其中包含“有冲突的一天与无冲突的一天列宽一致”“冲突卡片同时显示两门课名与两处地点”“切到标准档恢复分栏”。详细范围与边界见 [验证记录](../product/1.6.1/VERIFICATION.md)。
