# v1.5.2 固定课表布局验证

本次针对固定课表仍显得留白偏大的反馈，收紧了行高、顶部排版和底部导航，并增加更窄的紧凑档。日期为 2026-09-09。

![固定课表与双向滚动](fixed-grid.jpg)

标准档每门并行课固定 196dp 宽，紧凑档约 70% 宽度并以更小字号折行；两档都不会根据屏幕强行把课程压成一字一行。标准行高 56dp 起，课名、地点和教师实际需要更多行时自动增加；空字段不占用额外说明行。长连堂课程仍使用同一节次的统一行高。

课表顶部缩为标题日期、当前课程卡、周导航和单行操作；底部导航缩短高度和图标文字。左右滑动日期、上下滑动节次；顶部星期和左侧节次刻度固定保持对齐。添加课程入口位于操作栏，不覆盖课程。

Android 15 的固定课表回归包含三门重叠课程、完整长标题、周日第 13 节、两轴手势和紧凑档宽度；Android 7 的固定布局与既有课表测试通过。横屏与 130% 系统字体通过。99 项 Kotlin 单元测试、11 项 Web 回归和 GitHub Actions 检查通过；正式签名构建仅 ARM64/ARMv7。

用户的 Android 17 实体设备及所有厂商字体/桌面行为仍未直接验证。截图使用演示课程，真实课表数据不会提交。
