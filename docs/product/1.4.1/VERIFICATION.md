# v1.4.1 视觉与小组件验证

范围：圆角极简桌面小组件，以及原生应用深色模式。所有截图使用 Android 15 模拟器和生成的演示数据。

## 设计变化

- 小组件使用 28dp 圆角、细边框与内边距，保留下一节及后两节课程的日期、时间、名称和地点。
- 紧凑尺寸采用三行摘要；标准和较大尺寸突出最近一节的时间与课程名。空课表提供明确的轻点添加提示。
- 浅色小组件采用柔和白底，深色为石墨灰底、薄荷绿重点；使用 Android 昼夜资源随系统主题变化。应用独立选择主题时，小组件仍跟随桌面系统主题。
- 应用深色模式改用中性灰阶，不再让背景、卡片和导航大面积偏绿；课程保留低饱和区分色，下一节课面板降低亮度。

## 实际验证

- Pixel Launcher 上已有小组件自动刷新为新样式；确认圆角、三节课程内容、昼夜切换、点击打开应用。
- `WidgetRenderTest` 将实际 Glance 内容渲染为 Android RemoteViews，在 **180×110、250×220、300×270 dp** 三种尺寸下逐一验证浅色/深色和有课/空状态，共 **12 个组合**。三门示例课程都在可视边界内，圆角角点透明。
- 精确尺寸测试与 Launcher 截图分开记录：Launcher 的实际布局受网格、缩放和系统版本影响，不以固定 dp 测试冒充所有桌面实测。
- 与小组件相邻的提醒集成测试一起运行，**5 项通过**，验证关闭通知仍可读取课表、重排提醒及跨日去重。
- 人工检查课表、安排、录入与设置的深色页面，见本目录截图。
- 关键文字配色的 WCAG 对比度计算：深色主文字 15.67:1，深色辅助文字 7.16:1；小组件浅色辅助文字 4.62:1、深色辅助文字 8.11:1。这里只校验指定配色，不构成完整无障碍认证。

测试数据已恢复，模拟器主题恢复为浅色。APK 构建与 Lint 的详细日志位于 Git 忽略的 `apk/android/build/widget-*.log`。本地 x86_64 仅用于调试，发布仅包含 ARM64/ARMv7。

最终 `assembleRelease` 与 `lintRelease` 成功（0 错误、40 条提示）；两个包均通过签名验证，包版本 1.4.1 / versionCode 7，ELF 检查确认每包只包含对应 ARM 架构。APK 不含模型权重或签名密钥。

## 验证限制

本轮没有在 ARM 真机和其他厂商桌面重复安装测试，也未覆盖所有系统字体缩放。圆角通过 drawable 提供旧系统的绘制回退，Android 12+ 另外应用 Glance 的 cornerRadius；旧系统回退尚未在对应版本设备上实测。
