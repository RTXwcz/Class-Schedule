# 我的课表 v1.4.0

这次更新围绕日常使用重新打磨原生界面，并修复独立审查发现的数据与安全问题。

## 更清晰的课表，更自然的选择

- 新的深绿与暖白视觉体系、稳定课程配色、下一节课提示和深色模式。
- 日期和时间改为滚轮选择，覆盖学期、调休、考试、日程及每日作息；自动处理月份天数和闰年。
- 横屏使用紧凑工具栏，展开课表时保留时间刻度；连堂课程继续显示为一张连续卡片。
- “全部课程”可管理所有已保存课程，包括暂未在当前周生效的安排。
- MCP 提供分步连接引导、配置复制、写入确认说明和故障排查。

## 本版修复

- 修复 Web 导入考试/日程 ID 导致的存储型 HTML 注入，并更新离线缓存。Web/PWA 用户也应更新部署资源。
- 恢复备份时，记录与学期、单双周和作息规则一起提交，避免新旧数据混合。
- 修复跨午夜提前提醒、跨日提醒去重和 MCP 清空确认期间的规则覆盖。
- 改进图片方向解析与删除确认。

## 下载与升级

- `class-schedule-v1.4.0-arm64-v8a.apk`：ARMv8 / 64 位 ARM Android，推荐大多数现代手机。
- `class-schedule-v1.4.0-armeabi-v7a.apk`：ARMv7 / 32 位 ARM Android。
- 系统要求 Android 7.0+。没有 x86/x86_64 发布包，不包含 OCR 模型权重。
- 附带对应源码和 `SHA256SUMS.txt`。正式签名与 v1.3.0 一致，可覆盖升级并自动迁移数据；跨 debug/release 签名切换前须导出备份。

## 验证与说明

通过 83 项单元测试、32 项 Android 模拟器集成测试、1 项旋转 JPEG 识别测试和 11 项 Web 回归。已人工检查滚轮、MCP 引导、浅色/深色和横屏。

MCP 使用可信局域网内的 HTTP，未提供传输加密；云端识别会向配置的 API 服务发送所选图片。真实手机的后台行为和真实课表识别准确率尚未进行全面基准测试。
