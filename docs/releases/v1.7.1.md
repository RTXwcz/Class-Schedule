# 我的课表 v1.7.1

这一版修掉一处识别拆分错误，并把课表卡片上的信息收敛到学生真正要读的四个字段。

## 用户可感知的变化

- `微积分（甲）I` 这类“标题 + 末尾短编号”的课程不再被拆成两门课。
- 课表卡片只显示科目、教学楼、教室、教师；非每周课程额外显示单双周。节次区间、`1-8周` 和课程备注不再重复堆在卡片上，需要时到编辑器或“全部课程”里看。
- 图片识别写进备注的内容也一并收敛：只有“需自备实验服”这类真正额外的信息才会保留。
- 设置 → 图片导入不再罗列推荐模型，只保留地址与模型名的填写说明。

## 安装与验证

要求 Android 7.0+。沿用原正式签名，可覆盖升级。附件只有 ARM64 与 ARMv7 两种 APK、对应源码与 `SHA256SUMS.txt`，不含 x86/x86_64 与 OCR 模型权重，开源协议 GPL-3.0-only。

单元测试 110 项全部通过，Android 15 设备测试 80 项中 76 项通过、4 项按环境前提跳过（需预置 OCR 模型或指定测试图片）。详细范围与边界见 [验证记录](https://github.com/RTXwcz/Class-Schedule/blob/v1.7.1/docs/product/1.7.1/VERIFICATION.md)。
