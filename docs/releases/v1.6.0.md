# 我的课表 v1.6.0

这一版处理课表的两处显示问题：连堂课被拆成多行时不再出现一叠碎卡片，最窄档保证整周都在屏幕内。

## 连续同门课自动合并

- 同一天里连续节次、课名/教学楼/教室/教师/周次/单双周完全相同的记录合并成一张卡片，导入或手工录入把连堂课拆成“第 1 节 / 第 2 节”也不再多出重复卡片。
- 中间缺一节、教室不同、周次或单双周不同、不同星期，都保持分开显示，不会误合并。
- 合并只发生在显示层：课程数据不变，“全部课程”仍是原始记录，点开合并卡片编辑的是其中第一节，不会把合并跨度写回。

![连续同门课合并](https://github.com/RTXwcz/Class-Schedule/blob/v1.6.0/docs/product/1.6.0/merged-lesson.png)

## 最窄档整周入屏

- 列宽改为按当周真实列数反算：某天有并行课程时会自动收窄，七天始终整体显示在屏幕内，不用先滑到右边才能看到周日。
- 411dp 屏幕上即使出现 10 列（周一 2 栏、周三 3 栏）也能整周入屏。

![并行课程下整周入屏](https://github.com/RTXwcz/Class-Schedule/blob/v1.6.0/docs/product/1.6.0/overview-parallel-week.png)

## 安装与验证

要求 Android 7.0+。沿用原正式签名，可覆盖升级。附件只有 ARM64 与 ARMv7 两种 APK、对应源码与 `SHA256SUMS.txt`，不含 x86/x86_64 与 OCR 模型权重，开源协议 GPL-3.0-only。

Android 15（411dp）与 Android 7.0（360dp）各跑通同一套 60 项设备测试，其中包含连堂合并的四组判定、点击合并卡片后编辑单节记录、以及并行课程下七天全部入屏。详细范围与边界见 [验证记录](../product/1.6.0/VERIFICATION.md)。
