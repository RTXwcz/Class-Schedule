# 我的课表 v1.5.1

课表现在使用固定阅读尺寸，通过左右滑动查看日期、上下滑动查看各节课，不再把七天和重叠课程自动压窄。

- 每门并行课程固定196dp宽，课名完整换行；多门同时上课时横向展开。
- 星期日期固定在顶部，节次时间固定在左侧，与滑动内容同步。
- 统一节次高度，完整显示长课名、地点和教师，保持连堂与不同天同节对齐。
- 移除展开/整周切换；日期跳转定位目标星期，主页面切换保留浏览位置。
- 添加课程入口移到上方操作栏，避免遮住末节课程。

99项Kotlin单元测试、正式构建和Release Lint通过。Android7.0/15验证固定宽度、长标题、连堂、双向滑动与末节定位；Android15另检查横屏及130%系统字体。具体证据与边界见验证记录。

要求Android7.0+，沿用既有签名，可覆盖升级。附件仅有ARM64与ARMv7两种APK、源码和SHA256SUMS；不含x86/x86_64和OCR权重，开源协议GPL-3.0-only。
