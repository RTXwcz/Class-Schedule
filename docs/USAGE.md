# 使用指南

## 建立课表

1. 在“设置 → 课表与提醒 → 每日作息”设置每天节数与每节起止时间。点按时间后上下滚动小时和分钟，停稳后确认。
2. 进入“录入”，手动添加课程，或选择图片识别。课程的“上课时段”可选择星期及起止节次；例如第 3–5 节会显示成一张跨三节的卡片。
3. 如果课程限定周次，先设置学期开始日期。单双周可选；关闭时保留原规则并按每周显示，明确周次集合仍生效。
4. “全部课程”始终显示所有已保存课程，包括因周次、调休或学期未设置而暂不出现在周课表中的记录。

## 日期、时间和调休

所有原生日期与时间字段使用滚轮，点按中心附近的值也可选择。日期滚轮自动处理闰年和月份长度，例如从 1 月 31 日切换到 2 月会落在该月最后一天。

调休是指定日期改上目标星期的整天课程，单双周仍依据该实际日期所在的学期周计算。更换一条调休的日期会替换原规则，不留下两条记录。

## 考试与日程

“安排”按日期显示考试和日程，可按类型筛选。创建时选择日期；打开“全天安排”可省略时间，关闭后选择开始时间。地点备注和普通备注分开保存。

## 提醒和小组件

首次进入时按系统提示授予通知权限。在“上课提醒”中查看权限状态，精确闹钟权限需根据系统提示开启。部分厂商还会限制后台活动，需要在设备设置中允许应用运行。

提醒只针对课程，默认提前 10 分钟。连堂课程按第一节开始时间提醒一次。桌面长按空白处，进入系统小组件菜单添加“我的课表”。

小组件可按桌面支持的方式调整大小。五种尺寸均保留标题与日期、首课的大号时间/课程/地点、分隔线和后两课，通过字号与间距适配；长名称显示省略号，完整信息可在应用中查看。空组件轻点后进入“录入”，已有课程时进入“课表”。小组件跟随系统深浅主题，应用内的独立主题选择不改变桌面主题。

## 备份与恢复

在“录入 → 数据备份”导出或选择 JSON 文件。恢复会替换当前整个课表数据集，包括课程、考试、日程、调休和解释它们的学期/作息规则；确认前请先导出当前数据。

数据库替换使用事务：成功后整份数据生效，失败时不留下新旧混合的数据集。API 密钥、MCP Token、界面主题和通知权限不随课表 JSON 迁移。

## 图片识别与校对

在“设置 → 图片导入”选择 tiny 或 small 并主动下载；两种模型均在本机运行。导入支持不等宽表格、清晰格线中的跨节课程和折行标题；小图会在必要时使用第二种识别尺度核对低置信文字。格线不清、缺少表头或图片未提供的信息不会被可靠补全，应用前需要核对摘要并补齐缺失的必填内容。

识别完成后，各门课程默认折叠，显示课名、星期节次、地点、教师、周次和备注摘要。点击课程卡片可展开编辑，时段使用滚轮选择；不再要求逐条勾选确认。底部固定“应用识别结果”，有效结果一次追加到当前课表。若存在缺项或无效时段，点击按钮会定位待补充课程；选填信息可以留空。

“统一周次”默认保留每门课程原有的单双周规则和周次范围，只改动你主动选择的部分。“移除此课程”后可以撤销，返回后再继续校对仍可撤销最近一次移除。

校对页顶部有“返回”和独立“放弃”。页面返回或系统返回会保留当前应用会话中的识别和修改，可从“继续校对”恢复；有键盘时，系统返回可能先收起键盘。放弃需要再次确认。保存或放弃当前结果后，才能识别另一张图片。未保存的草稿不保证跨应用进程结束保留，完成校对后请保存到课表。

## 外观与操作位置

在“设置 → 课表与提醒 → 外观”选择“松林绿”或“鸢尾紫”，再独立选择“跟随系统 / 浅色 / 深色”。配色保存在本机；桌面小组件使用相同配色并继续跟随系统明暗。

切换主页面会保留录入模式、安排筛选、设置分区、课表与其他页面可保存的滚动位置。“安排”优先列出今天与未来事项，过去记录从“查看过去安排”展开。由“全部课程”进入编辑后，保存或取消会回到原列表位置。

课程时段弹窗的修改仅在“确定时段”后应用，取消和系统返回保留原时段；滚动未停稳时暂不能提交。“全天安排”往返切换会保留之前选好的时间。手动课程和考试/日程编辑中，有修改时误按系统返回或点遮罩会询问是否放弃；正常保存和显式取消保持直接操作。

## 课表浏览方式

默认的全览档按屏幕宽度把七天排进一屏，同一时段多门课并排展开，当天可以占多列；课名使用固定字号并完整换行，不会把字号等比压小。切到标准或宽松档后左右滑动浏览不同天，上下滑动浏览不同时段。顶部星期日期与左侧节次时间固定保留，并与内容同步。

课表有两种浏览方式，右上角按钮显示当前档位，点按按“全览 → 标准 → 宽松”循环：

- **全览（默认）**：列宽按屏幕宽度自动计算，七天一屏，课名折行显示，适合先看整体。
- **标准** 92dp、**宽松** 130dp：固定列宽，一屏约四天 / 三天，适合看单节课的完整信息。

拖动课表时两个方向一起跟手：一次滑动可以同时换到别的星期和别的节次，不必先横着划一次再竖着划一次；松手后会按手势速度继续滑行一段，新一次触摸立刻停住。双指捏合可以随时连续调整列宽（40–220dp）：捏宽了自动进入拖动档，捏到比全览还窄会自动吸附回全览，保证七天完整入屏；捏合过程中也能直接拖动定位。切换档位时按比例保留横向浏览位置；课名与地点始终按列宽折行，不会把字号压成竖排，也不会出现信息被裁切。

同一天里连续节次、同一门课（课名、教学楼、教室、教师、周次、单双周都相同）的课程会自动合并成一张卡片，因此导入课表时把连堂课拆成“第 1 节 / 第 2 节”两行也不会显示成两张碎卡片。合并只发生在这个视图里：课程数据没有变化，“全部课程”里仍是原来的记录，点开合并卡片编辑的是其中第一节，不会把合并后的跨度写回。若两节之间缺一节、或教室/周次不同，则仍按两张卡片显示。

全览档每天固定占一列，列宽由七天平分（411dp 屏约 49dp、360dp 屏约 42dp），因此星期与日期、教学楼与教室在任何课表下都保持完整可读，七天也永远整屏显示。同一天里时间互相冲突的课程不会并排把整周挤宽，而是在这一列内合成一张卡片，逐条列出每门课的课名与地点，中间用细分隔线分开；需要并排对照时切到标准或宽松档，那里仍按分栏显示。

## 图片导入能读到什么

导入课表图片时，识别会把图上能落进表的信息都填进对应字段：课程名（含折行标题）、星期、节次、单周/双周、周次范围、教师、教学楼与教室、地点备注。地点里的括号会原样保留，例如「紫金港田径场（东）」「紫金港风雨操场（羽毛球场）」；`紫金港东2-204` 这类会拆成教学楼「紫金港东」与教室「2-204」。

如果图片左侧印着作息时间，应用还会识别「一天多少节课、每节课几点到几点」，在复核页顶部给出「识别到 N 节作息」，点「应用为每日作息」即可覆盖设置里的作息，课程提醒与桌面小组件会跟着更新；时间轴缺行或时间不连续时不会采用，避免把节次编号改错。

用云端识别时，设置里填服务根地址即可（应用会自动补 `/v1/chat/completions`），模型要选支持图片输入的，例如 DeepSeek 的 `deepseek-flash`、中转站的 `Qwen3.8-Flash-Next`。填完可以用「测试连接」验证地址、Key 与模型名是否匹配；服务端返回的错误原文会直接显示出来。

节次高度按内容分配：空节次保持紧凑，只有被课程覆盖的节次会被撑高，同一天与跨天仍共用同一套行边界。课程卡片只显示真实存在的信息，没有地点、教师或备注时不会留下空行。日期跳转、“今天”和切换周会定位相应星期，从第一节开始浏览；标题区、周导航和当前课程压成紧凑三行，底部导航为居中窄条，图标与文字始终在槽位内。切换主页面后保留滚动位置，添加课程入口位于课表上方操作栏，不遮挡末尾课程。
