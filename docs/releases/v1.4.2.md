# 我的课表 v1.4.2

本次更新修复桌面小组件的录入入口和识别结果的返回流程，改进折行课程名解析，并清理 Android 安装包中的旧桥接依赖。

## 小组件

- 空课表时轻点提示或卡片进入“录入”，可以添加课程、考试或日程；已有课程时进入“课表”。
- 处理应用已经打开时的重复点击，并为新 Android 版本补齐 Widget Activity 启动选项。
- 不同尺寸保留统一层级：最近一节的大号时间、课程和地点，以及后两节的日期与摘要；缩放通过字体和间距适配。
- 继续保留圆角、浅色与石墨灰深色配色，小组件跟随系统昼夜主题。

## 图片导入

- 校对结果顶部增加返回与独立“放弃”按钮。系统返回与页面返回都保留未保存内容，可在导入页继续校对。
- 放弃需要确认；已有待校对内容时，先保存或放弃，再选择下一张图片，避免覆盖先前的修改。
- 改进不等宽表格、闭合单元格、课程节次跨度与折行标题解析，减少把一个课程名称拆成多门课程的情况。
- 对小尺寸图片增加第二种识别尺度，避免用跨行候选重复覆盖原始文字。tiny 与 small 均使用同一套表格解析和逐项校对流程。

图片缺少的教师、地点、周次等信息仍需补充；识别后的内容在确认保存前不会写入现有课表。模型保持按需下载，APK 不包含权重。

## 原生构建与安装包

Android 端移除旧 Capacitor/Cordova 运行时桥接和未使用的文件共享配置，启用代码压缩与资源收缩。Web/PWA 继续独立提供。原生开发可直接使用 Gradle 构建，无需 npm 同步；图标生成工具仍可按需使用。

发布目标为 Android 7.0 及以上的 ARM 系统：现代 64 位手机选 `arm64-v8a`，32 位 ARM 系统选 `armeabi-v7a`。公开附件仅提供这两种 APK，不提供 x86/x86_64 或通用 APK。

正式版本沿用既有签名后可覆盖升级；debug 与正式签名不同，切换前需导出 JSON 备份。最终附件同时提供对应源码与 `SHA256SUMS.txt`。

## 验证范围

90 项 Kotlin 单元测试、11 项 Web 回归、正式构建与 Release Lint 通过。在 Android 7.0 和 15 验证组件导航、OCR 返回/放弃、MCP、提醒及 30 种组件渲染组合；Android 15 的两种模型分别通过一张人工核对课表的 30 条课程名称、星期和完整节次断言。

Android 16 直接安装正式签名 ARM64 包（模拟器 ARM 转译），通过两模型下载和识别、返回与放弃、MCP 鉴权/确认写入/读回及同签名升级。未验证红米 K90 Pro Max／澎湃 OS 4／Android 17，也不将单张样本结果当作所有图片的准确率保证。图片缺失的字段仍需补充，识别结果需要校对后保存。
