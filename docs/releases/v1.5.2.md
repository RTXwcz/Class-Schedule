# 我的课表 v1.5.2

本版继续收紧固定课表的视觉密度，适合你提供的长课表排版。

- 标准课表行高从 68dp 收紧到 56dp，只有实际文字需要时才增加空间。
- 紧凑档约为标准列宽的 70%，课程名称使用更小字号折行，适合查看更多课程。
- 顶部标题、当前课程卡、周导航和操作区重新压缩；底部导航栏高度、图标和文字同步收紧。
- 保留固定课程宽度、星期与节次刻度对齐、左右日期/上下节次滑动、长课名换行及连堂边界。

要求 Android 7.0+。正式附件只提供 ARM64/ARMv7，沿用正式签名；不提供 x86/x86_64，不包含 OCR 模型权重。应用采用 GPL-3.0-only。

Android 7.0/15、横屏、130%系统字体、重叠课程、周日第13节和紧凑档均已验证。完整边界见 [验证记录](../product/1.5.2/VERIFICATION.md)。
