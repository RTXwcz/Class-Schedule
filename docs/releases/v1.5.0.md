# 我的课表 v1.5.0

这次更新减少课表录入中的重复操作，并增加可选的「鸢尾紫」主题。

## 折叠校对，一次应用

- 每门识别结果默认折叠，摘要展示课名、星期节次、地点、教师、周次和备注；展开即可编辑。
- 取消逐字段确认框，底部固定“应用识别结果”，一次追加全部有效课程。缺少必填信息时直接定位待补充项，选填字段可留空。
- “统一周次”只修改主动选择的规则或范围，默认保留各门课程原有信息。
- 移除课程可以撤销，返回再继续校对也保留最近一次撤销机会。
- 保存中防重复点击，已应用、已放弃或过期草稿回调不会再次追加。

## 鸢尾紫主题

在“设置 → 课表与提醒 → 外观”选择松林绿或鸢尾紫，再独立选择跟随系统、浅色或深色。应用按钮、卡片、下一节课面板和桌面小组件同步配色。已有安装默认保留绿色；小组件的明暗继续跟随系统。

## 常用操作改进

- 主页面之间切换保留录入模式、安排筛选、设置分区及可保存的滚动位置。
- “安排”优先显示今天和未来事项，过去记录从单独入口展开。
- 课程时段滚轮只在确认后应用，取消和系统返回保留原值；时段、每日节数及调休星期均等待滚动停止后再提交。
- 全天安排往返切换保留原时间；从全部课程编辑后返回原列表位置。
- 手动课程、考试和日程草稿有修改时，隐式返回会提供继续编辑或放弃；正常保存与显式取消保持直接操作。

## 安装与验证

要求 Android 7.0+。沿用原正式签名，可覆盖升级。发布附件仅提供 **ARM64（45.15 MiB）和 ARMv7（32.59 MiB）** 两种 APK、对应源码和 SHA-256 校验文件，不含 x86/x86_64 或 OCR 模型权重。代码采用 GPL-3.0-only。

99 项 Kotlin 单元测试和 11 项 Web 回归通过，正式构建与 Release Lint 通过。Android 7.0 和 15 验证新版操作流程与主题选择；Android 15 验证两种配色的 60 场景小组件渲染，以及实际 ARM64 正式包启动和主题持久保存。精确范围与截图见验证记录，未将这些结果扩大为所有厂商和系统版本的保证。
