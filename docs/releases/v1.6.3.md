# 我的课表 v1.6.3

这一版把课表图片里的作息也读出来，并修好 OpenAI 兼容接口的可用性。

## 从课表读作息

- 解析图片时间轴：一天多少节课、每节课几点到几点。复核页顶部出现「识别到 N 节作息」，一键「应用为每日作息」，提醒与小组件随之更新。
- 要求每节都有起止时间、节次连续，缺行时不采用，避免把节次编号改错。
- 真实截图实测 13 节全部正确（08:00-08:45 … 20:30-21:15）。

## 地点不再丢括号

- `紫金港田径场（东）`、`紫金港风雨操场（羽毛球场）` 原样保留。
- `紫金港东2-204` 仍拆成教学楼「紫金港东」+ 教室「2-204」；`体育馆（东）A301` 保留为「体育馆（东）」+「A301」。

## 云端识别修复

- 地址只填服务根地址也能用，自动补全 `/v1/chat/completions`。
- 请求显式 `stream: false`，兼容默认流式的网关。
- 把服务端的错误原文和状态码一起显示；把控制台首页当 API 地址（返回网页）时会明确提示。
- 设置页新增「测试连接」，并写明模型必须支持图片输入。
- 实测可用：DeepSeek `https://api.deepseek.com` + `deepseek-flash`；中转站 `https://direct.abinapi.com` + `Qwen3.8-Flash-Next`（走 `/v1`）。

## 安装与验证

要求 Android 7.0+。沿用原正式签名，可覆盖升级。附件只有 ARM64 与 ARMv7 两种 APK、对应源码与 `SHA256SUMS.txt`，不含 x86/x86_64 与 OCR 模型权重，开源协议 GPL-3.0-only。

单元测试 102 项、Android 15 设备测试 66 项全部通过。详细范围与边界见 [验证记录](https://github.com/RTXwcz/Class-Schedule/blob/v1.6.3/docs/product/1.6.3/VERIFICATION.md)。
