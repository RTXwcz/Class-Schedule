# 原生课表易用性目标

目标：优化界面；模型下载改用 hf-mirror.com；单双周可选；导入与手动填写并存；增加考试和日程类型；自定义每天节数及各节时间；多节连堂连续显示。

实现范围：

1. 原生课表默认一屏整周，提供展开视图、今天强调和课程次数；导航为课表/安排/录入/设置。
2. 录入页并列提供手动填写、图片识别和数据备份。复用现有课程编辑器及日期安排编辑器。
3. 新安装单双周默认关闭；旧设置保留原行为。关闭后不删除原规则，课程按每周生效，明确周集合仍适用。提醒、Widget、MCP 与 UI 使用相同开关。
4. 考试与日程共用已存在的日期记录，添加 EXAM/EVENT 类型和普通备注。旧 JSON 及数据库记录默认 EXAM；通过显式 v2→v3 迁移保留数据。JSON、MCP 与 Web 保留新字段。
5. 模型文件使用镜像源和原始固定提交/SHA-256，仍仅在主动下载后落盘。校验失败不可激活模型。
6. 每日作息支持 1–48 个按先后排列、不重叠、不跨午夜的 HH:mm 时间段。用户逐节设置，JSON 保留；旧数据默认原 12 节。减少节数不得隐藏已有课程。提醒和 Widget 从自定义开始时间计算，MCP 写入不得超出配置节数。
7. 开始节次到结束节次对应一张连续课程卡，横跨所有相关行；仅在同一时段有多门课程时分列。新增第 13 节显示与第 3–5 节单块跨度设备断言。

验收：领域与往返测试、旧数据库迁移、录入及分类 UI 设备测试、镜像实际下载及推理、浅色/深色/窄屏截图，以及可安装 APK。结果记录于 `../verification/2026-09-07-usability-verification.md`。
